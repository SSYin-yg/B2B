## 一、文件位置

| 文件 | 位置 | 用途 |
|------|------|------|
| `backend/.env` | Strapi 目录 | 后端运行时全部配置（密钥/数据库/SMTP/站点地址/重发密钥） |
| `backend/.env.example` | Strapi 目录 | 配置模板（入库，不含真实值） |
| `.env` | 项目根目录 | 构建脚本用（`STRAPI_URL`、`SITE_URL`，构建时读取） |

> ⚠️ 历史 `.env.bak-*` 文件曾被误提交进 git（私有仓库），密钥轮换仍列待办；`.gitignore` 已覆盖，勿再创建带真实值的备份入库。

## 二、backend/.env 完整变量清单

```bash
# ===== 基础 =====
HOST=0.0.0.0            # 监听地址（仅本机 nginx 反代使用，防火墙勿对公网开 1337）
PORT=1337

# ===== Strapi 安全密钥（生产严禁默认值）=====
APP_KEYS="key1,key2,..."        # 逗号分隔多个随机串
API_TOKEN_SALT=tobemodified
ADMIN_JWT_SECRET=tobemodified   # 后台 JWT 签名（预览凭证约 30 分钟有效）
TRANSFER_TOKEN_SALT=tobemodified
JWT_SECRET=tobemodified
ENCRYPTION_KEY=tobemodified

# ===== 数据库（当前：PostgreSQL 17 本机）=====
DATABASE_CLIENT=postgres
DATABASE_HOST=127.0.0.1
DATABASE_PORT=5432
DATABASE_NAME=strapi_db
DATABASE_USERNAME=strapi_user
DATABASE_PASSWORD=<真实密码>
DATABASE_SSL=false
DATABASE_SCHEMA=public
DATABASE_POOL_MIN=0
DATABASE_POOL_MAX=10
DATABASE_CONNECTION_TIMEOUT=60000

# ===== 询盘邮件（任一留空则不发信，询盘仅入库）=====
SMTP_HOST=               # 如 smtp.qq.com
SMTP_PORT=465
SMTP_USER=
SMTP_PASS=               # 邮箱服务商授权码（非登录密码）
SALES_EMAIL=             # 询盘通知收件邮箱

# ===== 站点地址（IP/端口变更用 scripts/update-site-url.sh 一键更新）=====
SITE_URL=http://<IP或域名>:<端口>/   # sitemap/绝对链接用，带尾斜杠
CLIENT_URL=http://<IP或域名>:<端口>   # 预览兜底地址，不带尾斜杠（可留空，
                                     # 预览 URL 优先动态取访问 Host）

# ===== 询盘重发接口密钥 =====
RETRY_KEY=<32位随机串>   # POST /api/inquiry/resend 的 x-retry-key 请求头，勿泄露

# ===== 遥测 =====
STRAPI_TELEMETRY_DISABLED=true
STRAPI_DISABLE_TELEMETRY=true
```

## 三、变量详解

### Strapi 安全密钥

| 变量 | 作用 | 泄漏后果 |
|------|------|---------|
| APP_KEYS | Session 签名 | 会话被伪造 |
| API_TOKEN_SALT | API Token 哈希盐 | Token 被逆向 |
| ADMIN_JWT_SECRET | Admin JWT 签名 | 后台登录被伪造（可接管内容） |
| JWT_SECRET | 插件 JWT 签名 | 同上 |
| TRANSFER_TOKEN_SALT | 数据迁移 Token 哈希 | 迁移被伪造 |
| ENCRYPTION_KEY | 敏感字段加密 | 数据被解密 |

生成命令：`openssl rand -base64 32`（或 `node -e "console.log(require('crypto').randomBytes(32).toString('base64'))"`）。修改后需重启 Strapi，且所有已登录后台会话/已签发 Token 失效。

### SITE_URL / CLIENT_URL

- `SITE_URL` 决定 sitemap.xml、hreflang、canonical、JSON-LD 中的绝对 URL——**改 IP/端口后必须同步更新并重建**，否则 SEO 数据指向旧地址。注意构建脚本读的是**项目根目录 `.env`**，两处需一致。
- IP/端口变化后执行：`./scripts/update-site-url.sh http://<新地址>`（自动备份、更新两处 .env、触发重建）。
- 后台预览 URL 动态取浏览器访问的 Host，IP 变化无需额外处理。

### RETRY_KEY

`POST /api/inquiry/resend` 的唯一鉴权（请求头 `x-retry-key`）。该接口对公网开放，必须保持强随机；泄露后任何人可向销售邮箱批量触发发信。

### DATABASE_*

连接信息同时被 `backend/config/database.js` 与 `scripts/backup-db.sh`（读取 .env 执行 pg_dump）使用。数据库为本机 PostgreSQL 17（systemd 管理），备份见 `backups/db/`。

### SMTP_* / SALES_EMAIL

询盘提交后转发通知邮件。未配置或配置错误时询盘**照常入库**（`email_sent=false`），仅不发信；后台 Maillog 可查每次发信结果。修改后需重启 Strapi。

## 四、项目根目录 .env（构建脚本）

```bash
STRAPI_URL=http://127.0.0.1:1337   # build-pages.js 拉取数据的 API 地址
SITE_URL=http://<IP或域名>:<端口>/   # 生成的 sitemap/绝对链接前缀
```

仅 `scripts/build-pages.js`（及 webhook-listener 预览渲染）读取；改动后重新运行构建即生效，无需重启 Strapi。

## 五、生效方式速查

| 改动 | 生效条件 |
|------|---------|
| backend/.env 任何值 | 重启 Strapi |
| 根目录 .env | 下一次 `build-pages.js` 运行 |
| SITE_URL/CLIENT_URL | 重启 Strapi + 重新构建（`update-site-url.sh` 一次完成） |
