# 09 - 环境变量配置说明

## 一、文件位置

本项目有三处 `.env`：

| 文件 | 位置 | 用途 |
|------|------|------|
| `backend/.env` | Strapi 根目录 | 后端运行时（SMTP、数据库、密钥） |
| `backend/.env.example` | Strapi 根目录 | 配置模板（入库，不含真实值） |
| `.env` | 项目根目录 | 构建脚本使用（`STRAPI_URL`、`SITE_URL`） |

## 二、backend/.env 完整变量清单

```bash
# ===== 基础 =====
HOST=0.0.0.0
PORT=1337

# ===== Strapi 安全密钥（首次启动生成，生产环境严禁复用默认值）=====
APP_KEYS="toBeModified1,toBeModified2"
API_TOKEN_SALT=tobemodified
ADMIN_JWT_SECRET=tobemodified
TRANSFER_TOKEN_SALT=tobemodified
JWT_SECRET=tobemodified
ENCRYPTION_KEY=tobemodified

# ===== 数据库 =====
# DATABASE_CLIENT 可选 sqlite / mysql / postgres
DATABASE_CLIENT=sqlite
DATABASE_HOST=
DATABASE_PORT=
DATABASE_NAME=
DATABASE_USERNAME=
DATABASE_PASSWORD=
DATABASE_SSL=false
DATABASE_FILENAME=.tmp/data.db

# ===== 询盘邮件 =====
SMTP_HOST=
SMTP_PORT=465
SMTP_USER=
SMTP_PASS=
SALES_EMAIL=sales@minelink.cn

# ===== 站点 =====
SITE_URL=https://ssyin-yg.github.io/B2B/

# ===== 前端预览 =====
CLIENT_URL=http://localhost:3000
```

### 变量详解

#### Strapi 安全密钥

| 变量 | 长度 | 作用 | 泄漏后果 |
|------|------|------|---------|
| APP_KEYS | 至少 32 字节 each | Session 签名 | 会话被伪造 |
| API_TOKEN_SALT | 至少 16 字节 | API Token 哈希盐 | Token 被逆向 |
| ADMIN_JWT_SECRET | 至少 64 字节 | Admin JWT 签名 | 登录被伪造 |
| JWT_SECRET | 至少 64 字节 | 插件 JWT 签名 | 同 |
| TRANSFER_TOKEN_SALT | 至少 16 字节 | 数据迁移 Token 哈希 | 迁移被伪造 |
| ENCRYPTION_KEY | 至少 32 字节 | 敏感字段加密 | 数据解密 |

**生成命令**：

```bash
node -e "console.log(require('crypto').randomBytes(64).toString('base64'))"
# 每次执行得到不同值
```

#### 数据库

SQLite 模式只需 DATABASE_CLIENT 和 DATABASE_FILENAME。切换 MySQL / Postgres 时按需填写其他变量。

#### SMTP

详见 [06-邮件通知配置手册](./06-邮件通知配置手册.md)。

#### SITE_URL

被 `scripts/build-pages.js` 读取，用于生成 canonical URL、OG Image 绝对地址、sitemap.xml 的 `<loc>`。

**格式要求**：**结尾必须带 `/`**。

✅ 正确：`https://ssyin-yg.github.io/B2B/`  
❌ 错误：`https://ssyin-yg.github.io/B2B`

#### CLIENT_URL

被 Strapi Admin 的 Preview 配置读取，用于生成预览按钮的 URL。

**格式要求**：**结尾不带 `/`**。

✅ 正确：`http://localhost:3000`  
❌ 错误：`http://localhost:3000/`

## 三、项目根目录 .env

```bash
# 站点配置（scripts/build-pages.js 使用）
SITE_URL=https://ssyin-yg.github.io/B2B/
STRAPI_URL=http://localhost:1337
```

| 变量 | 被谁读取 | 说明 |
|------|---------|------|
| STRAPI_URL | build-pages.js | API 基础地址 |
| SITE_URL | build-pages.js | 站点域名（生成绝对 URL） |

如果项目根目录没有 `.env`，脚本会回退到硬编码默认值（STRAPI_URL=`http://localhost:1337`、SITE_URL=`https://ssyin-yg.github.io/B2B/`）。

## 四、环境变量加载顺序

```
1. shell 环境变量（最高优先级）
2. backend/.env（Strapi 自动加载）
3. .env（build-pages.js 手动加载，不覆盖已有变量）
4. config/*.js 中的 env('KEY', 默认值) 兜底
```

`env('KEY', 'default')` 是 Strapi 提供的 helper，会从 shell + .env 中查找。

## 五、敏感信息保护

| 文件 | 是否入库 | 原因 |
|------|---------|------|
| `backend/.env` | ❌ 必须不入库 | 含密钥、SMTP 密码 |
| `backend/.env.example` | ✅ 必须入库 | 模板，占位符 |
| `.env`（根目录） | ❌ 不入库建议 | 不含密钥，但 SITE_URL 可公开 |

### .gitignore 检查

确保 `.gitignore` 包含：

```
.env
backend/.env
backend/.tmp/
backend/public/uploads/
node_modules/
```

## 六、常见问题

### Q1：改了 .env 但没生效？
A1：**必须重启 Strapi 进程**。`.env` 只在启动时加载一次。

### Q2：SMTP 配置在生产服务器改了但还是发不出去？
A2：确认 `backend/.env` 在生产服务器正确放置 + 重启 Strapi（`pm2 restart strapi` 或 `systemctl restart strapi`）。

### Q3：如何验证当前加载的 .env？
A3：在 Node 中执行：
```bash
cd backend
node -e "require('dotenv').config({path: '.env'}); console.log(process.env.SMTP_HOST);"
# 或者直接看启动日志（Strapi develop 模式会打印部分配置）
```

### Q4：SITE_URL 和 CLIENT_URL 混淆？
A4：
- **SITE_URL** → 前端静态页的**公开地址**（SEO canonical / sitemap / OG）
- **CLIENT_URL** → Strapi Admin 预览按钮打开的**本地地址**（开发时 localhost:3000，生产时与 SITE_URL 相同）
