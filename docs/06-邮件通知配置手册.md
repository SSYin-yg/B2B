# 06 - 邮件通知配置手册

## 一、概述

询盘表单提交后，系统通过 Nodemailer 将表单内容转发到销售邮箱 `sales@minelink.cn`。

邮件触发入口：`backend/src/api/inquiry/controllers/inquiry.js` 的 `sendMail()` 函数。

## 二、SMTP 配置

所有配置项集中在 `backend/.env`：

```bash
# SMTP 询盘邮件转发（必填后询盘才会发邮件；留空则仅入库）
SMTP_HOST=
SMTP_PORT=465
SMTP_USER=
SMTP_PASS=
SALES_EMAIL=sales@minelink.cn
```

| 变量 | 必填 | 说明 |
|------|------|------|
| SMTP_HOST | ✅ | SMTP 服务器地址（如 `smtp.gmail.com`、`smtp.qq.com`） |
| SMTP_PORT | 否 | 默认 465（SSL/TLS）；也可以 587（STARTTLS） |
| SMTP_USER | ✅ | 邮箱账号 |
| SMTP_PASS | ✅ | 邮箱密码或**授权码**（很多邮箱服务需要授权码而非登录密码） |
| SALES_EMAIL | ✅ | 收件人（固定为 `sales@minelink.cn`，可修改为实际销售邮箱） |

### 端口与加密

```javascript
// 实际代码：backend/src/api/inquiry/controllers/inquiry.js
secure: port === 465,  // port=465 时 SSL；其他端口 STARTTLS（nodemailer 自动升级）
```

| 端口 | 加密方式 | 常见服务 |
|------|---------|---------|
| 465 | SSL/TLS（强制） | Gmail、QQ、163、Outlook |
| 587 | STARTTLS（协商升级） | Gmail、Outlook |
| 25 | 明文（不推荐） | 极少服务支持 |

## 三、主流邮箱服务商配置参考

### 腾讯企业邮（推荐国内客户用）

```bash
SMTP_HOST=smtp.exmail.qq.com
SMTP_PORT=465
SMTP_USER=sales@minelink.cn
SMTP_PASS=<企业邮箱登录密码>
SALES_EMAIL=sales@minelink.cn
```

### QQ 个人邮箱（仅测试）

```bash
SMTP_HOST=smtp.qq.com
SMTP_PORT=465
SMTP_USER=<your_qq>@qq.com
SMTP_PASS=<QQ邮箱授权码，不是QQ密码！>
```

⚠️ QQ 邮箱需要在"设置 → 账户"中开启 SMTP 服务并生成授权码。

### 163 邮箱

```bash
SMTP_HOST=smtp.163.com
SMTP_PORT=465
SMTP_USER=<your_account>@163.com
SMTP_PASS=<163邮箱授权码>
```

### Gmail

```bash
SMTP_HOST=smtp.gmail.com
SMTP_PORT=465
SMTP_USER=<your_account>@gmail.com
SMTP_PASS=<Google App Password>
```

⚠️ Gmail 需要开启两步验证后生成 **App Password**。Google 不再允许普通密码 SMTP 登录。

### 阿里云企业邮

```bash
SMTP_HOST=smtp.mxhichina.com
SMTP_PORT=465
SMTP_USER=sales@minelink.cn
SMTP_PASS=<登录密码>
```

## 四、邮件格式

### 邮件主题

```
【官网询盘】{equipment} - {customer_name}
```

示例：`【官网询盘】履带式颚式移动破碎站 - 张三`

### HTML 邮件正文

```
┌──────────────────────────────────┐
│ 官网新询盘                         │
├──────────────────────────────────┤
│ 设备          履带式颚式移动破碎站 │
│ 客户姓名      张三                  │
│ Email         zhangsan@example.com │
│ WhatsApp/电话 +86 13800000000      │
│ 国家/地区      印度尼西亚           │
│ 需求描述      需要处理花岗岩...      │
│ 提交时间      2026-09-03 11:30:00  │
├──────────────────────────────────┤
│ 此邮件由官网询盘系统自动发送...      │
└──────────────────────────────────┘
```

邮件同时发送 **纯文本版本**（text/plain）供纯文本邮箱客户端显示。

### 关键：HTML 转义

代码中所有邮件正文内容都经过 **HTML 转义**（`&` → `&amp;` 等），防止客户输入恶意脚本。

## 五、配置生效流程

```
1. 编辑 backend/.env（或生产服务器对应 .env 文件）
2. 保存
3. 重启 Strapi：npm run develop → Ctrl+C → npm run develop
4. 触发测试询盘（见第六节）
5. 检查 Sales 邮箱
```

⚠️ **必须重启** Strapi 才能重新加载 `.env`。Nodemailer 在每次发送时都会读取 `process.env`（当前代码实现），但 Strapi 进程启动时 .env 才会被注入。

## 六、测试 SMTP 配置

### 方法 A：通过前端表单

1. 确保 Strapi 已启动且 SMTP 已配置
2. 确保静态服务器在运行（或直接访问 Strapi 内的 API）
3. 打开任意设备页 → 填写表单 → 提交
4. 观察浏览器响应：`emailSent: true` 表示成功

### 方法 B：直接 curl API

```bash
curl -X POST http://localhost:1337/api/inquiry \
  -H "Content-Type: application/json" \
  -d '{"equipment":"test","customer_name":"test","email":"t@t.com","country":"US","message":"smtp test"}'
```

响应 `emailSent: true` 且邮箱收到邮件 → 配置正确。

### 方法 C：独立 Node 测试脚本

```javascript
// backend/scripts/test-smtp.js
require('dotenv').config();
const nodemailer = require('nodemailer');
async function main() {
  const transporter = nodemailer.createTransport({
    host: process.env.SMTP_HOST,
    port: Number(process.env.SMTP_PORT || 465),
    secure: Number(process.env.SMTP_PORT || 465) === 465,
    auth: { user: process.env.SMTP_USER, pass: process.env.SMTP_PASS },
  });
  await transporter.sendMail({
    from: process.env.SMTP_USER,
    to: process.env.SALES_EMAIL,
    subject: 'SMTP 测试',
    text: 'OK',
  });
  console.log('✅ 发送成功');
}
main().catch(console.error);
```

⚠️ 本仓库没有 dotenv 依赖，需要先安装：

```bash
cd backend && npm install dotenv
node scripts/test-smtp.js
```

## 七、SMTP 未配置的降级行为

当以下任意变量为空时，邮件**不会发送但询盘照常入库**：

- SMTP_HOST
- SMTP_USER
- SMTP_PASS
- SALES_EMAIL

日志输出：

```
[2026-09-03 11:34:00.202] warn: [inquiry] SMTP 未配置（SMTP_HOST/SMTP_USER/SMTP_PASS/SALES_EMAIL），询盘仅入库。
```

API 响应中 `emailSent: false`。

## 八、常见错误与排查

| 现象 | 可能原因 | 排查方法 |
|------|---------|---------|
| 响应 `emailSent: false` 且日志有 warn | SMTP 变量为空 | 检查 .env + 重启 |
| `ETIMEDOUT` / `ECONNREFUSED` | SMTP_HOST/端口不对或被防火墙拦截 | `telnet smtp.qq.com 465` |
| `EAUTH` / `535 Authentication failed` | 授权码错误或需要开启 SMTP 服务 | 重新生成授权码 |
| `550 Mailbox not found` | SALES_EMAIL 不存在 | 检查收件人邮箱拼写 |
| `554 Message rejected` | 发件人域名与 SPF/DKIM 不匹配 | 配置域名的 SPF 和 DKIM 记录 |
| 邮件进垃圾箱 | 缺少 SPF/DKIM 或内容被判定为垃圾 | 配置 SPF 记录：`v=spf1 include:_spf.google.com ~all` |

## 九、安全注意事项

1. **.env 不入库**：`backend/.env` 已在 `.gitignore` 中，确保 `.git/info/exclude` 或 `.gitignore` 包含 `.env`
2. **不要硬编码**：所有密钥只存在 `.env`
3. **日志脱敏**：Strapi 默认日志不会打印完整 SMTP_PASS，但排查时注意不要把日志粘贴到公开渠道
4. **发件人安全**：`from: SMTP_USER` — 发件邮箱必须与 SMTP 认证邮箱一致
